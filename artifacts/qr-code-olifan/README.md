# QR code Olifan

URL encodee : `https://go.pixsom.fr/olifan`

- `olifan-qr.svg` : fichier vectoriel recommande pour l'impression.
- `olifan-qr-2048.png` : version PNG 2048 px pour les usages bureautiques.
- Correction d'erreur : niveau H.
- Marge silencieuse : 4 modules.

Conserver le QR noir sur fond blanc, sans le recadrer ni modifier ses proportions. Faire un test sur papier avec
plusieurs telephones avant le tirage final. La destination se change avec `OLIFAN_REDIRECT_URL` sans regenerer le QR.
